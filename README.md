
# Personal Portfolio Website

A responsive personal portfolio website built with HTML and CSS. It showcases my background, technical skills, projects, and contact information.

**🌐 Live Demo:** [Visit My Portfolio](https://neha-ece.github.io/Personal-Portfolio/)

**📂 GitHub Repository:** [Personal-Portfolio](https://github.com/Neha-ECE/Personal-Portfolio)

## About This Project

I am an Electronics and Communication Engineering student at Rajkiya Engineering College, Sonbhadra, preparing for software engineering roles.

I built this website to present my skills and projects in one place while practicing front-end development and creating my professional online presence.

## Features

- Fixed header with navigation links
- Smooth scrolling between sections
- Home, About, Skills, Projects, and Contact sections
- Skill cards and project cards
- Responsive layout for desktop, tablet, and mobile screens
- Social links to GitHub and LinkedIn
- Keyboard focus styles and reduced-motion support

## Technologies Used

- **HTML5** — Semantic website structure
- **CSS3** — Styling and visual design
- **Flexbox and CSS Grid** — Page layout
- **CSS Media Queries** — Responsive design
- **Google Fonts (Poppins)** — Typography
- **Font Awesome** — Icons
- **Git and GitHub** — Version control and code hosting
- **GitHub Pages** — Website deployment

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Neha-ECE/Personal-Portfolio.git
   ```

2. Open the downloaded project folder in VS Code.
3. Open `index.html` in your browser.

No additional installation is required.
